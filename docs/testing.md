# الاختبارات — ما نُفِّذ فعلياً ونتائجه

## 1) محرك الحسابات والبروتوكول (Vitest)
```bash
npm test
```
```
✓ tests/engine.test.ts (22 tests) 22ms
  Test Files  1 passed (1)
       Tests  22 passed (22)
```

التغطية:
- أولويات العمليات و`^` الأسّية اليمنى الترابط.
- صيغة التدفق، الحقن الوزني، التدرج (عنصراً بعنصر)، الترحيل بالصيغتين.
- OLS (ميل، تقاطع، R²، بواقي)، SD(n−1)، %RSD، الحساسية النسبية.
- رفض `__import__`, `fetch`, `alert`, `process`, `;`, القسمة على صفر.
- حوكمة: `UNDER_REVIEW` على حدود `CONFLICT_REQUIRES_QA`، `PASS`/`FAIL` على المعتمدة.
- سلامة البروتوكول: 13 اختباراً، كل مقياس له `AUTHORITY_LIMIT`، كل معادلة تُحلَّل بنجاح.
- تشغيل كامل: 13/13 PASS، FAIL عند انحراف OOS، INCOMPLETE عند نقص البيانات، FAIL عند حساس تسرب.

## 2) محرك الخادم (pytest)
```bash
cd backend && pytest -q
```
```
21 passed in 0.03s
```
نفس متجهات الاختبار مع `Decimal` — يثبت تطابق المحركين.

## 4) غير المُنفَّذ بعد
- اختبارات تكامل API + قاعدة بيانات حقيقية (تتطلب مجمّع Docker الكامل).
- اختبارات الأمان الآلية (ZAP/Burp) — موصى بها قبل الإنتاج.
- اختبارات الحمل (k6) على ملايين القراءات.
- تغطية كود مُقاسة (coverage report) — مطلوبة في بوابة CI.
