# المعمارية

## النمط
**Modular Monolith** (Clean Architecture) — لا Microservices غير مبرَّرة.
الفصل الصارم: `api → services → repositories → models`، و`domain` مستقل تماماً عن I/O.

```
الطلب → Router → التحقق (Pydantic) → Policy (RBAC + قسم) → Service (منطق)
      → Domain (محرك AST + الحوكمة) → Repository → PostgreSQL
      → Audit (إلحاق فقط) → الاستجابة الموحدة
```

## الطبقات وممنوعاتها

| الطبقة | المسؤولية | ممنوع |
|---|---|---|
| `api/` | HTTP فقط: تحقق، استجابة، أكواد حالة | أي منطق أعمال |
| `services/` | تنسيق، Transactions، أحداث | استعلامات SQL مباشرة |
| `domain/` | محرك AST، الإحصاء، الحوكمة | أي I/O أو استيراد DB |
| `repositories/` | وصول البيانات المعزول | أي منطق أعمال |
| `models/` | SQLAlchemy ORM | منطق حسابي |

## قرارات أساسية
1. **محرك حسابي مزدوج متكافئ:** TypeScript للمتصفح (عمل بلا اتصال) وPython للخادم (المرجع).
   النتيجة: النظام يعمل في مختبر بلا شبكة، والمطابقة مضمونة باختبارات مشتركة.
2. **قيم كاملة الدقة:** لا تقريب قبل طبقة العرض، ولا `FLOAT` في أي مسار قياس.
3. **حوكمة كنقطة اختناق:** `evaluateMetric()` هي المكان الوحيد الذي يصدر حكماً — لا يمكن
   تجاوزها من أي route أو خدمة.
4. **Invariant على مستوى قاعدة البيانات:** Triggers تمنع تعديل سجل التدقيق والنتائج المقفلة،
   حتى لو أُخطئ في طبقة التطبيق.
5. **الواجهة لا تقرر:** كل فحص صلاحية يُعاد على الخادم؛ إخفاء الأزرار تجربة استخدام فقط.

## ملاحظة على هذه الدورة
الواجهة الكاملة والمحرك يعملان الآن على IndexedDB (طبقة متصفح كاملة الوظائف)، بينما
الخادم الخلفي موثّق بهيكله ومحركه المرجعي المُختبَر. المزامنة بين الطبقتين هي المرحلة التالية،
ومخطط الجداول متطابق حرفياً لتكون المزامنة مباشرة.
